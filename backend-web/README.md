# HaloFactory 后端 Web 展示原型

[`smart-factory-mes-wireframe.html`](smart-factory-mes-wireframe.html) 是生产协同 MES 后端管理界面的单文件静态展示稿。

## 展示范围

- 订单总览与工序进度
- 订单建档和施工图上传界面
- AI 拆解草稿与生管确认
- 任务派发和车间人员分配
- 生产进度跟踪
- 成套能力、瓶颈风险和调整建议
- 装配质检、包装入库和基础资料

## 查看方式

下载或克隆本仓库后，直接使用现代浏览器打开 `smart-factory-mes-wireframe.html`。该文件不需要安装依赖或启动服务器。

这是静态交互原型，不包含实际后端接口、身份认证或数据持久化。页面中的订单、人员、产量和生产进度均为演示数据，不代表真实生产记录。
